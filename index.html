1

Pasta de Extração de Dados no seu PC

O aplicativo lê os dados da sua carreira gerados pelo Live Editor diretamente desta pasta dedicada na Área de Trabalho (separada dos arquivos do programa).

Pasta exclusiva para dados do save:

O Live Editor salva planilhas e relatórios como FC_CAREER_VAULT_BACKUP.json, jogadores_contratos.csv e SCOUT_LIVE_DATABASE.json dentro de Dados_Carreira_FC.

2

Onde Colocar o Script Lua no Live Editor (Patch FCM / EA SPORTS FC)

No Patch do FC Mania (FCM), a pasta do Live Editor fica localizada dentro da pasta do seu jogo EA SPORTS FC. Você só precisa de um único script: o EXTRAIR_DADOS_CARREIRA.lua.

Estrutura de Pastas no Patch FCM (EA FC 24, FC 25, FC 26, FC 27+):
📁 C:\Program Files\EA Games\EA SPORTS FC\ (ou C:\Arquivos de Programas\EA Games\EA SPORTS FC\)
  └── 📁 Live Editor\  (Pasta do Live Editor integrada ao FCM)
        └── 📁 lua\
              └── 📁 scripts\
                    └── 📄 EXTRAIR_DADOS_CARREIRA.lua  (Script Mestre Único)
O que este script único faz automaticamente:

Gera a planilha jogadores_contratos.csv (com todos os 25.000 jogadores, contratos, clubes e atributos para o Scout), atualiza seu elenco, finanças, histórico de transferências, classificação e calendário em tempo real!

3

Como Extrair os Dados Dentro do Jogo (1 Clique)

A extração é 100% segura, rápida e não altera nada no seu save da carreira.

Passo A

Inicie o Jogo

Abra o EA FC pelo launcher do Live Editor e carregue seu Modo Carreira.

Passo B

Aperte F9

Pressione a tecla F9 no seu teclado para abrir o menu flutuante do Live Editor.

Passo C

Aba Lua Scripts

Vá na aba Lua Scripts e selecione EXTRAIR_DADOS_CARREIRA.lua.

Passo D

Clique em Run Script

Clique em Run Script. Em menos de 2 segundos, os dados da carreira são extraídos!

💡 DICA PRO: AUTORUN AUTOMÁTICO

No menu de Lua Scripts do Live Editor, você pode marcar a caixinha Autorun ao lado de EXTRAIR_DADOS_CARREIRA.lua. Assim, ele extrairá os dados automaticamente sempre que você avançar o calendário ou terminar um jogo!

Como Extrair no Jogo pelo Live Editor:

  1. Abra o EA Sports FC através do Live Editor e carregue seu Modo Carreira.
  2. No menu do Live Editor, acesse a aba Lua Scripts.
  3. Selecione o script EXTRAIR_DADOS_CARREIRA.lua (ou lua/career_vault_sync.lua).
