# Avatares das Personalidades e Mídia

Guarde as fotos de perfil e logos nesta pasta para que o aplicativo as carregue automaticamente. 

## Nomes de Arquivo Esperados:
Para que o carregamento funcione sem problemas, salve os arquivos no formato **PNG** ou **JPG** com os seguintes nomes exatamente:

- `casimiro.png` - Casimiro (Cazé TV)
- `galvao.png` - Galvão Bueno
- `maurocezar.png` - Mauro Cezar
- `pvc.png` - PVC (Paulo Vinícius Coelho)
- `neto.png` - Craque Neto
- `sbt_sports.png` - SBT Sports
- `romano.png` - Fabrizio Romano
- `neymarjr.png` - Neymar Jr
- `cristiano.png` - Cristiano Ronaldo
- `pepguard.png` - Pep Guardiola
- `specialone.png` - José Mourinho
- `haaland.png` - Erling Haaland
- `ge.png` - GE Globo
- `espn.png` - ESPN Brasil
- `tnt.png` - TNT Sports
- `band.png` - Band Sports

*Nota: Se a imagem não for encontrada, o aplicativo usará automaticamente um avatar dinâmico em SVG baseado na inicial do nome.*
